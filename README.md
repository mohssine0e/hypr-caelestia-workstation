# Hypr Caelestia Workstation

Personal Arch Linux Hyprland + Caelestia/Quickshell workstation config.

This repository tracks the current working setup so changes can be reviewed,
committed, rolled back, and eventually migrated from Hyprland `.conf` files to
Hyprland Lua config safely.

## Tracked Areas

- `config/hypr` - active Hyprland config snapshot
- `config/caelestia` - personal Caelestia config snapshot
- `config/quickshell/caelestia` - customized Quickshell/Caelestia shell files

## Working Rule

Read `TASKS.md` before making changes. Work feature by feature, verify, commit,
and push only after the setup still works.
